03 — Workflow

From repo to ranked in three steps.

No SDKs. No webhooks to set up. Connect a GitHub repo and we do the indexing.

01

Claim your project.

Find your repo, click claim, prove ownership via a one-line commit. Takes 38 seconds. We'll wait.

● Verified via GitHub OAuth
02

We auto-crawl.

Every 5 minutes we pull releases, OG images, README diff, contributor activity. You ship; we score.

● Last crawl 2m 14s ago
03

Climb the board.

Ship more, post weekly updates, be honest in pauses. The score reflects momentum, not vanity downloads.

● Updated every Monday 09:00 UTC
